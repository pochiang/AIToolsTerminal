工作狀況

Claude Code 與 Codex 可用 ask_session 把問題送進另一個對話並取回回覆。反問正在等自己的對話一律禁止。

「回合」從你在該對話按下 Enter 起算；轉介層數 1 = 只能直接詢問，對方不能再轉問別人。

沒有可詢問的對話時，AI 可用 open_session 在背景開一個新頁籤（標上 [AI]，與發起方同資料夾）。每個新對話都會消耗用量。

每次 ask_session 前，先把任務與請求交給 Jev 評分，分數不夠就請 AI 自行完成。Jev 連不上時一律放行。金鑰以 Windows 加密保存。
